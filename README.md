## 🔥 Featured Projects

### 🇮🇳 NITI Aayog AI Scheme Matcher

**AI-assisted platform for discovering relevant government schemes for marginalized entrepreneurs.**

**Tech:** `Node.js` `Express.js` `PostgreSQL` `AI/ML` `REST APIs`

* Matches entrepreneurs with relevant government schemes using profile-based parameters.
* Processes demographic, financial and geographic information.
* Designed with a backend architecture focused on scalability and secure API communication.
* Built as part of an AI-driven solution for improving access to government schemes.

🔗 **[Live Demo](https://nitiyog.onrender.com/dashboard)**

---

### 🪙 Mints — Short-Form Video Platform

A mobile-first short-form content platform focused on **video discovery, engagement and reward mechanisms**.

**Tech:** `Flutter` `Node.js` `Express.js` `PostgreSQL` `Cloudinary`

* Designed a short-form video feed and interaction system.
* Implemented transactional reward logic using PostgreSQL.
* Integrated Cloudinary for media storage and asynchronous uploads.
* Built the backend around RESTful APIs and scalable service architecture.

---

### 🔐 Almanca — Personal Cloud Platform

A private cloud platform designed for storing and managing personal files.

**Tech:** `Node.js` `Express.js` `MongoDB` `EJS`

* Multi-format file storage and categorization.
* Authentication and session-based security.
* Role-based endpoint authorization.
* Designed with privacy-focused access control.

🔗 **[View Source Code](https://github.com/SakshamBharat/Almanaca)**
